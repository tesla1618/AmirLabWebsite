Implementation / usage

Rules for adaptable interfaces.

A reusable system should make shared patterns easy to keep and project identity easy to change.

PRACTICE

Do

  • Give one action visual priority in each group.
  • Use monospace for shortcuts, counts, and compact metadata.
  • Keep borders thin and surfaces close in value.
  • Choose a heading style that fits the project's voice and keep body copy easy to read.
  • Give imagery and section openers enough room to breathe.

Avoid

  • Applying the accent to large backgrounds or every link.
  • Stacking shadows, gradients, and heavy borders on the same surface.
  • Using display sizes for long paragraphs or dense controls.
  • Communicating status through color alone.
  • Assuming one palette or type pairing fits every project.
